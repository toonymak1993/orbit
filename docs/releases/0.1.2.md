# ORBIT 0.1.2

ORBIT 0.1.2 is the stable conclusion of the Beta 1 and Beta 2 line.

ORBIT 0.1.2 brings the complete Beta 1 and Beta 2 feature line into one stable,
controller-first Windows release. It expands the launcher far beyond a single
store while making Xbox Mode installation, updates, background controller input
and artwork management considerably more reliable.

## Highlights

- **A complete gaming home:** Browse Steam, Xbox, PlayStation, Epic, GOG, EA,
  Ubisoft, custom games and retro libraries from one controller-friendly UI.
- **More ways to shape Home:** Choose ORBIT, Rolling, FLOAT, CoreSense or XMODE.
  The new Rolling layout brings a wide active game forward and adds recent
  activity, friends and recommendations through ORBIT Pulse.
- **Your own background:** Let Home follow the selected game, pin one game,
  rotate through your library or use a personal wallpaper. Background movement
  can be still, gently drifting or cinematic.
- **Better artwork:** Covers, backgrounds, icons and transparent game logos can
  be found automatically or selected manually. Automatic artwork can now be
  cleared or rebuilt without removing hand-picked images.
- **Applications and friends:** Launch installed media apps and tools, add custom
  Windows applications, follow friends across supported networks and open
  Discord conversations or servers.

## Games and integrations

- PlayStation purchases, PS Plus and play history can be imported, with Remote
  Play launching through detected Chiaki-ng or Sony software.
- GOG, EA app and Ubisoft Connect installations are detected locally.
- Xbox and Xbox 360 discovery reconciles installed packages, Microsoft game
  configuration and Store identities. Direct installation requests use Windows
  first and fall back safely to the Xbox app when required.
- Retro libraries support ROM folders, system browsing, emulator/core detection,
  supported portable setup, fullscreen launch profiles and optional
  RetroAchievements.
- Provider-aware launch arguments, stronger process matching and manual session
  tracking reduce false launches and improve return-to-ORBIT behavior.

## Reliability, input and security

- The background controller service is supervised and can recover from monitor
  or agent failures while keeping its Windows startup state consistent.
- Updates and uninstall operations now suspend that service transactionally and
  restore it when an installer cannot start, avoiding locked files and silent
  controller outages.
- DualSense, XInput, media controls and controller navigation are more resilient,
  including clearer focus movement between content, LT/RT layers and the main
  navigation.
- SteamGridDB tokens are encrypted with Windows credential storage, migrated
  from older plaintext settings without exposing them to the renderer, and can
  be checked or removed from Settings.
- The Xbox Mode installer handles a missing `GamingHomeApp` registry value and
  keeps its authored flow in English.

## Installing and upgrading

The release provides one required download:
`ORBIT-XboxMode-Setup-0.1.2-x64.exe`.

Beta 2 uses the same Certum publisher line and is expected to update in place.
Beta 1 used the former self-signed publisher and needs a manual all-in-one
installation. Its legacy package must remain installed until users have confirmed
their data in the Certum-signed build; the stable migration flow must not delete
package-family-scoped data automatically.

Xbox Mode requires Windows 11 24H2 or newer and remains subject to Microsoft's
regional, device-policy and phased-rollout availability.
