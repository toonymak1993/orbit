# ORBIT 0.1.2 Beta 2

ORBIT 0.1.2 Beta 2 is a public prerelease for community testing. The stable `latest` release remains `0.1.1`.

## Download

Download only **`ORBIT-Beta-XboxMode-Setup-0.1.2-beta.2-x64.exe`** from the [GitHub prerelease](https://github.com/toonymak1993/orbit/releases/tag/v0.1.2-beta.2).

This is the only file required. The English all-in-one setup contains the complete ORBIT application, the Xbox Mode AppX, the public Certum certificate and the validated installation flow. Stable installations remain on the stable update channel.

## Important Beta 1 transition

Beta 1 pins the former self-signed publisher and therefore cannot accept a differently signed installer through automatic update. Beta 1 users must download and run this all-in-one setup manually once.

The Certum-signed AppX belongs to a new Windows package family. Setup installs and validates it first, but deliberately keeps the legacy self-signed package and its development certificate installed. Windows does not support `PreserveApplicationData` for removing a packaged Beta 1 AppX, and package data can be scoped to the old publisher-derived family. Automatic removal would risk deleting user state.

After setup opens **Settings > Gaming > Xbox mode**, select the visibly distinct **ORBIT Beta** entry. Keep the legacy **ORBIT** package until you have confirmed that your settings, library, artwork and integrations are present in Beta 2. The new setup does not add or remove a certificate in a Windows Root or TrustedPeople store.

Future releases on the Certum signing line can update normally because Beta 2 pins the new signer.

## New in Beta 2

- Added the first publicly trusted ORBIT release-signing line using Certum SimplySign, SHA-256 and an RFC3161 timestamp.
- Added direct Xbox and Microsoft Store game installation requests through Windows, with a safe Xbox-app fallback when Windows cannot start the requested product installation.
- Improved Xbox and Xbox 360 library discovery by reconciling Microsoft Game configuration data, Store product IDs and installed-package evidence.
- Expanded Xbox download monitoring across request, streaming, staging, installation and update phases.
- Improved the download activity island with Xbox artwork, product context and clearer progress states.
- Added Discord server discovery to the Friends Hub and direct hand-off to Discord for server channels.
- Added hierarchical controller navigation between page content, LT/RT layers and the main navigation so focus movement is more predictable.
- Fixed the Xbox Mode installer failure on Windows accounts where the optional `GamingHomeApp` registry value does not exist.
- Kept the all-in-one installer and its diagnostics in English while leaving Windows-owned UAC, SmartScreen and Settings screens in the user's Windows language.
- Added targeted regression coverage for Xbox installation requests, Xbox library reconciliation, Discord integration and spatial controller navigation.
- Made the Certum publisher transition non-destructive and labelled the new Gaming Home registration **ORBIT Beta** so it can be distinguished from legacy **ORBIT**.

## Beta and trust notice

This is prerelease software. Xbox Mode requires Windows 11 24H2 (build `10.0.26100.0`) or newer and remains subject to Microsoft's regional, device-policy and phased-rollout availability.

The public signature removes the Unknown Publisher condition, but Microsoft SmartScreen may still warn while this new certificate and binary build reputation. Do not disable SmartScreen system-wide. Verify the file hash and signer below before choosing **More info > Run anyway**.

Emulator setup remains user-initiated. ORBIT pins and verifies the primary RetroArch, Dolphin and Project64 packages and restricts downloads to official HTTPS hosts. Some optional upstream emulator assets and RetroArch cores still do not publish immutable checksums, so automatic provisioning remains a beta feature.
