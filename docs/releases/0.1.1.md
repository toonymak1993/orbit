# ORBIT 0.1.1

ORBIT 0.1.1 is the second stable release and the first version with safe in-app
update support. The public download remains a single self-contained Xbox Mode
installer.

## Highlights

- **Friends Hub:** See Steam, Epic and optional Discord friends, presence,
  activities and last-seen information in one controller-friendly view.
- **A better organized library:** Favorites, custom collections, adjustable
  4–8-column layouts and lossless multi-store handling make large libraries
  easier to browse without collapsing distinct editions.
- **Artwork Studio:** Search for or import covers, backgrounds and icons,
  including local files and clipboard images.
- **Quick Settings and status HUD:** Battery, power, network and Bluetooth status
  stay accessible without leaving ORBIT, with shortcuts to the relevant Windows
  settings.
- **Safer game launches:** A three-second cancel window, stricter process
  matching, provider-aware timeouts and clearer failure states reduce false
  launches and give users time to stop an accidental start.
- **More controller support:** The DualSense PS button can open ORBIT over USB and
  both supported Bluetooth report formats.

## Reliability and store improvements

- Steam, Epic and Xbox synchronization now preserves valid cached games during
  partial provider failures instead of removing them from the library.
- Epic keeps usable entitlements when catalog metadata is unavailable and better
  handles EA- and Ubisoft-managed titles.
- Xbox fills missing metadata from Microsoft's display catalog and keeps Game
  Pass ownership separate from purchased titles.
- Xbox download activity now follows streaming, staging, content staging,
  installation and update phases as one progress flow. Completed packages are
  added without a full slow rescan.
- Store caches remain useful during provider outages, and the rolling release
  calendar accepts more real-world release-date formats.

## Updates and installer

- Packaged builds can find the correct GitHub release, pause downloads while a
  game or launcher download is active, resume interrupted transfers, and verify
  both the GitHub SHA-256 digest and the pinned Authenticode signer before the
  installer runs.
- ORBIT 0.1.0 predates the updater, so existing 0.1.0 users must install 0.1.1
  manually once. Later correctly versioned releases can use the in-app flow.
- The all-in-one Xbox Mode setup now uses English as its only authored installer
  language.
- Installation no longer fails when Windows has the Gaming Configuration key but
  has not created its optional `GamingHomeApp` value yet.
- The installer remains idempotent, validates the AppX and Gaming Home contract,
  and keeps Windows Settings responsible for selecting the active home app.

## Download and trust notice

Download only `ORBIT-XboxMode-Setup-0.1.1-x64.exe` from the official GitHub
release. It contains the complete Xbox Mode package and installation flow.

This release is still signed with the self-signed `CN=ORBIT Development`
certificate while public code-signing verification is pending. Windows may show
an unknown-publisher or SmartScreen warning. Compare the SHA-256 hash and signer
thumbprint shown in the GitHub release notes before installing. Do not disable
SmartScreen system-wide.

Xbox Mode requires Windows 11 24H2 or newer. Availability also depends on
Microsoft's supported markets, device policy and phased rollout.
