# ORBIT 0.1.2 Beta 1

ORBIT 0.1.2 Beta 1 is a public prerelease for testing the largest feature expansion since 0.1.1. The stable `latest` release remains 0.1.1.

## Download

Download only `ORBIT-Beta-XboxMode-Setup-0.1.2-beta.1-x64.exe` from the [GitHub prerelease](https://github.com/toonymak1993/orbit/releases/tag/v0.1.2-beta.1).

The English all-in-one setup contains ORBIT, the Xbox Mode AppX, the public signing certificate and the verified installation flow. The final SHA-256 and signer thumbprint are published both on this page and in the GitHub release notes.

## Highlights

- Added a controller-friendly Applications hub for media apps, installed launchers, Discord, graphics tools and custom Windows applications.
- Added PlayStation purchases, PS Plus and play-history import, with launching through detected Chiaki-ng or Sony PS Remote Play installations.
- Added automatic local game detection for GOG, EA app and Ubisoft Connect.
- Added ROM folders, system browsing, emulator and core detection, supported portable-emulator setup, fullscreen launch profiles and optional RetroAchievements.
- Added Discord conversations, unread indicators and message notifications through the optional Discord Social SDK integration.
- Added XMODE, an Xbox-inspired Home layout with quick launchers, Library search, offers and rotating picks.
- Added ORBIT and custom MP4 startup animations plus configurable dock themes, size and motion.
- Added the ORBIT Horizon wallpaper, with one-click desktop and lock-screen setup from Onboarding or Appearance settings and separate status reporting when Windows policy blocks one target.
- Added provider and category filters, five sorting modes, retro-system views, provider badges and reversible hide controls.
- Improved Steam and RetroAchievements synchronization, artwork discovery and fallbacks, direct Steam installation requests, provider launch arguments, process detection and manual session tracking.
- Added a controller on-screen keyboard and controller bridges for supported media web apps.

## Beta and trust notice

This is prerelease software intended for testing. PlayStation support uses the community-maintained `psn-api` project and is not affiliated with Sony or PlayStation. Retro users must provide their own legally obtained games and any required BIOS or firmware. Third-party services and web interfaces can change independently of ORBIT.

Emulator setup is always user-initiated. ORBIT pins and verifies the primary RetroArch, Dolphin and Project64 packages, constrains downloads to official HTTPS hosts, and validates archive boundaries. Some optional upstream emulator assets and RetroArch cores do not currently publish immutable checksums, so automatic provisioning remains a beta feature and will be hardened further before a stable release.

ORBIT currently uses the self-signed `CN=ORBIT Development` certificate while public code-signing verification is pending. Windows may display an unknown-publisher or SmartScreen warning. Verify the SHA-256 and signer information below; do not disable SmartScreen system-wide.

Xbox Mode requires Windows 11 24H2 or newer and remains subject to Microsoft's regional, device-policy and phased-rollout availability.
