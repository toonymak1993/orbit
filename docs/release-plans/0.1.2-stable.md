# ORBIT 0.1.2 Stable Release Plan

Status: **release candidate built and verified on 2026-09-02 — publish from the exact tagged commit**

ORBIT 0.1.2 is the stable conclusion of the Beta 1 and Beta 2 line. The goal is
to ship the complete console-oriented launcher as one publicly trusted Windows
installer without introducing another feature wave during stabilization.

## Target

- Product version: `0.1.2`
- Windows and AppX version: `0.1.2.2`
- Release sequence: `12`
- Channel: `stable`
- Git tag: `v0.1.2`
- Public binary: `ORBIT-XboxMode-Setup-0.1.2-x64.exe`
- Distribution: one manually uploaded all-in-one EXE; GitHub's automatic source
  archives remain available

The all-in-one installer must contain the complete desktop application, Xbox
Mode AppX and validated English installation flow. The standalone NSIS installer
and AppX remain verification inputs and must not be uploaded as additional
public binaries.

## Stable scope

The release combines the Beta 1 Applications, PlayStation, external-library,
retro, Discord, XMODE, personalization and controller work with Beta 2's public
signing, Xbox installation/discovery, download progress and navigation changes.
The post-Beta-2 stabilization adds:

- the Rolling Home layout with Library Pulse, recent activity, friends and
  recommendations;
- focus, pinned-game, library-slideshow and custom Home backgrounds with
  independent motion settings;
- game logos across Home layouts, expanded artwork selection, cache maintenance
  and secure SteamGridDB credential storage;
- a supervised background controller service with bounded restart, recovery,
  Windows login-item reconciliation and clear managed/repair states;
- transactional update and uninstall hand-off so the background service cannot
  keep files locked or remain disabled after a failed installer launch;
- more resilient DualSense, XInput, hardware-control and media-controller
  monitoring.

No unrelated feature should enter the stable branch after release preparation
starts. Confirmed correctness, migration, accessibility or security fixes remain
in scope.

## Required blockers before build

- Move the remaining personal Steam Web API key out of renderer-visible settings
  and into Windows `safeStorage`, including fail-closed legacy migration.
- Exercise the complete Rolling Home and background settings flows at 1280x720
  and 1920x1080 with keyboard/controller navigation, reduced motion, missing
  artwork and both English and German text.
- Validate the background service through enable, disable, repair, crash,
  application update, cancelled uninstall, completed uninstall and reboot/login.
- Validate clean install, Beta 2 upgrade and direct Beta 1/self-signed migration
  on clean Windows 11 24H2 or newer systems. The Beta 1 path must make the new
  Certum package distinguishable without deleting legacy package-family data.
- Confirm a Beta 2 installation updates in place to the stable Certum package and
  that **ORBIT** remains selectable under Settings > Gaming > Xbox mode.
- Resolve or explicitly accept every optional emulator asset that still lacks an
  immutable upstream digest.

## Mandatory signing contract

Every public Windows executable and package must be signed in its final byte
form with the same Certum SimplySign identity:

- Subject: `CN=Open Source Developer Luis Antonio Garcia Roque, O=Open Source Developer, L=Alfdorf, S=Baden-Württemberg, C=DE`
- Thumbprint: `61E90C0AACBF2F407A575903FCC197F45B61706D`
- Timestamp server: `http://time.certum.pl`

The final gate must verify the signer and RFC3161 timestamp on the inner
`ORBIT.exe`, standard NSIS installer, Xbox AppX and public all-in-one EXE. The
private key, SimplySign token, PIN and mobile authorization must never enter the
repository or release artifacts. No file may be changed after signing.

## Verification matrix

1. Run `git diff --check`, both TypeScript projects and the production build.
2. Run the complete functional verification suite, with special attention to
   updates, background service, DualSense/media input, spatial navigation,
   artwork, Xbox reconciliation and provider-library preservation.
3. Build the stable standard installer and Xbox all-in-one package through the
   repository's Certum-aware Windows scripts.
4. Run `verify:win`, `verify:xbox` and an independent extraction/hash comparison
   of the all-in-one payload.
5. Perform the clean-Windows and upgrade matrix above without weakening
   SmartScreen, certificate stores or Windows security policy.
6. Pass the ORBIT Guardian quality gate with no unresolved blocker.
7. Merge through a reviewed GitHub pull request, tag the exact `main` merge
   commit and create a draft GitHub release.
8. Upload only the all-in-one EXE, download it again from GitHub, and re-verify
   SHA-256, size, Authenticode signer and timestamp before publishing.
9. Publish as the stable Latest release only after all integrity values have
   replaced the placeholders in `docs/releases/0.1.2.md`.

## Go/no-go rule

The stable release is a no-go if signing is unavailable, a required artifact has
the wrong signer or no timestamp, the background service can remain disabled
after a failed update, Beta migration can delete data, credentials cross into the
renderer, or an incomplete clean-Windows matrix has not been explicitly accepted
by the release owner after the public beta phase.

## Release-candidate evidence

- TypeScript validation, production build and all 26 functional verification
  targets passed on Windows 11 25H2.
- `verify:win` and `verify:xbox` passed for version `0.1.2.2`.
- `ORBIT.exe`, the standard installer, AppX and all-in-one setup have the pinned
  Certum signer and RFC3161 timestamps.
- Independent 7-Zip extraction matched the embedded AppX, public certificate
  and English installer script byte-for-byte with their verified sources.
- Smart App Control remained enabled; the release pipeline statically extracts
  electron-builder's temporary uninstaller rather than executing an unsigned
  NSIS bootstrap.
- The public all-in-one setup is `176,937,664` bytes with SHA-256
  `389d376dfe88f736ae15e63ca7b68e64dfd5341ff3e348c5767820503b629533`.

No disposable clean-Windows VM was available on the release host. The final
Guardian decision must therefore carry the clean-install and real Beta 2
upgrade matrix as explicit residual risk; the package itself passed the
side-effect-free install validator without weakening Windows security policy.
The release host does have healthy legacy `0.1.2.0` and Certum-signed Beta 2
`0.1.2.1` package registrations side by side, which confirms retention and the
publisher transition without mutating the installed packages during this gate.
